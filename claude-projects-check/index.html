양식·자료 정리 준비도 자가진단

Claude Projects 시작 전, 우리 회사 양식·자료 정리 준비도 점검

자주 쓰는 양식과 자료가 Projects에 올릴 준비가 됐는지, 8가지 항목으로 직접 점검해 보세요.

적용 안내

이 진단은 Claude Projects에 양식·자료를 올리기 전에 정리 수준을 점검하는 참고용 도구입니다.

근거: Anthropic 도움말(Projects 구성·파일 개당 최대 30MB·컨텍스트 표준 200,000 토큰·무료 요금제 최대 5개·공유는 Team·Enterprise 요금제), Anthropic 데이터 사용 안내(개인 요금제 Free·Pro·Max는 모델 개선용 데이터 사용 여부를 설정에서 직접 정할 수 있음, 상용 요금제 Team·Enterprise·API는 기본적으로 학습에 쓰지 않음). 기준일: 2026-11-26.

※ 주의: 요금제·한도·정책은 바뀔 수 있으니, 중요한 문서를 올리기 전에는 Anthropic 도움말과 사내 방침으로 직접 확인하세요.
Projects 준비 절차 (4단계)
1단계: 양식·자료 모으기 가장 자주 찾는 양식부터 한곳에 모으기
2단계: 지시문 쓰기 자주 안 바뀌는 규칙만 적기
3단계: 자료 올리기 최신 버전만 올리고 낡은 버전은 삭제
4단계: 새 대화에서 바로 쓰기 새 조건만 입력하면 기준은 이미 정해져 있음
Projects는 정리된 자료를 바탕으로 답합니다. 자료가 최신 버전인지 먼저 확인하세요.
양식·자료 정리 수준 — 4단계
단계 상태 특징
1단계 흩어짐 양식이 개인 PC·메일함에 흩어져 있음 찾을 때마다 다시 묻고 다시 설명함
2단계 모음 공유 폴더에 양식을 모아 둠 찾을 곳은 정해졌지만 버전이 섞여 있음
3단계 표준화 양식·버전·작성 기준을 문서로 정리함 담당자가 바뀌어도 같은 양식으로 이어짐
4단계 Projects 양식·지시문·자료를 Projects에 일원화 새 대화에서도 같은 기준이 바로 적용됨
준비도 진단 문항 (8항목)
힌트: 양식부터 정해져 있어야 Projects에 올릴 것이 정해집니다.
힌트: 최신 버전을 찾는 곳이 정해져 있지 않으면, 낡은 양식으로 답하게 됩니다.
힌트: 파일명에 기간을 붙이면(예: 가격표-2026-Q3.pdf) 낡은 기준을 참조하지 않습니다.
힌트: 담당자가 바뀌어도 이어지면, 기준이 사람 머릿속이 아니라 문서에 있다는 뜻입니다.
힌트: 자주 안 바뀌는 규칙은 지시문에 적고, 자주 바뀌는 사실은 파일에 둡니다.
힌트: 대화마다 다시 붙여넣고 있다면 Projects 효과가 큽니다.
힌트: 민감 정보는 지우거나 가린 사본으로 정리한 뒤 올리세요.
힌트: 대외비 문서는 사내 방침을 먼저 확인하고, 요금제별 데이터 정책을 확인하세요.
